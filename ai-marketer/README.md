# AI Marketer

Готовый проект для личного AI-маркетолога в Codex.

## Что делает этот проект
AI Marketer помогает предпринимателю создавать:
- маркетинговые стратегии
- контент-планы
- рекламные тексты
- офферы
- воронки продаж
- анализ конкурентов
- идеи для Instagram, TikTok, Telegram, YouTube Shorts

## Структура
```
ai-marketer/
├─ README.md
├─ marketer_profile.md
├─ prompts/
│  ├─ 01_strategy.md

│  ├─ 03_ads.md

└─ outputs/
   └─ example_result.md
```

## Как использовать
1. Заполни `briefs/client_brief_template.md` по своему проекту.
2. Прочитай роль и стандарты в `marketer_profile.md`.
3. Выбери нужный промпт из папки `prompts/`.
4. Вставь в Codex:
   - бриф клиента
   - содержимое выбранного промпта
5. Получи результат в едином формате из 10 блоков.

## Единый формат ответа (обязательный)
Каждый результат должен содержать:
1. Цель
2. Целевая аудитория
3. Боль клиента
4. Оффер
5. Каналы продвижения
6. Контент
7. Реклама
8. Воронка продаж
9. KPI
10. Следующие действия

## Рекомендация
Начни с `01_strategy.md`, затем переходи к контенту, рекламе и воронке.

## Готовый пример под ваш сайт (Presswall)
Если нужно быстро стартовать на основе сайта `presswall-presswall.ru`, используйте:
- `briefs/presswall_filled_brief.md` — заполненный бриф на основе публичных данных сайта
- `outputs/presswall_90_day_plan.md` — готовый 90-дневный маркетинг-план

> Важно: это рабочая версия с гипотезами. Уточните фактические цифры (маржа, текущие лиды, рекламный бюджет), чтобы повысить точность рекомендаций.
